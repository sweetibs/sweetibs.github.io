# brandonsweeting.com

Personal academic website of Brandon Sweeting, served by GitHub Pages at https://brandonsweeting.com. Plain HTML and CSS, no build step.

- `index.html`, `research.html`, `publications.html`, `teaching.html`, `outreach.html`: the pages (each shares the same header and footer)
- `css/site.css`: all styles, with light and dark color tokens at the top
- `images/`: headshot and favicon
- `uploads/curriculum_vitae.pdf`: the downloadable CV
- `404.html`: not-found page; also forwards old addresses from the previous site (e.g. `/publication/...`)
- `CNAME`: custom domain for GitHub Pages; `.nojekyll`: serve files as-is

To preview locally, open `index.html` in a browser.
